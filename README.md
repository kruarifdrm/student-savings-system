# ระบบออมทรัพย์นักเรียน

เว็บแอปบันทึกเงินออมของนักเรียนในห้อง สำหรับครูประจำชั้น ใช้บนมือถือได้เลย
ไม่ต้องติดตั้งโปรแกรม ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง — เป็นไฟล์ HTML ล้วน
เก็บข้อมูลบน Firebase Firestore (ใช้ฟรีในโควตาปกติของห้องเรียนทั่วไป)

แจกฟรีภายใต้สัญญาอนุญาต MIT เอาไปใช้ แก้ไข หรือแจกต่อได้

---

## ทำอะไรได้บ้าง

- **ฝาก / ถอน** เงินออมรายคน ด้วยแป้นตัวเลขบนมือถือ
- **ภาพรวมทั้งห้อง** ยอดรวม ยอดคงเหลือรายคน แตะดูประวัติรายคนได้
- **ประวัติรายการ** ทั้งห้องหรือรายคน ลบรายการที่บันทึกผิดได้ (ระบบปรับยอดคืนให้อัตโนมัติ)
- **ปริ้น / แชร์เป็นรูป** ใบสรุปยอดออม ใบประวัติรายการ กรองตามเดือนและประเภทได้
- **แยกสิทธิ์ครู / ผู้ปกครอง** ครูเข้าด้วยบัญชี Google ถึงจะฝาก-ถอนได้
  ผู้ปกครองเข้าดูได้อย่างเดียว ไม่มีปุ่มฝาก-ถอน
- **แท็บตั้งค่า (เฉพาะครู)** จัดการรายชื่อนักเรียนในแอปได้เลย — เพิ่ม แก้ชื่อ ลบ
  ใส่รูปประจำตัว และ **นำเข้า / ส่งออก CSV** พร้อมไฟล์ตัวอย่างให้ดาวน์โหลด
- **เพิ่มครูคนอื่นได้ในแอป** ไม่ต้องแก้ไฟล์และ deploy ใหม่ทุกครั้ง
- **บอกเองเมื่อมีเวอร์ชันใหม่** กดตรวจสอบได้จากแท็บตั้งค่า

---

## ⚠ อ่านก่อนใช้ — เรื่องความเป็นส่วนตัว

**ทุกคนที่รู้ลิงก์เว็บ เปิดดูข้อมูลได้ทันทีโดยไม่ต้องล็อกอิน**

ระบบออกแบบให้ผู้ปกครองเข้าดูได้ง่ายที่สุด (ไม่ต้องสมัคร ไม่ต้องจำรหัส)
แอปจึงสร้างบัญชี anonymous ให้เองเมื่อเปิดเว็บ แล้วให้สิทธิ์ **อ่านอย่างเดียว**
ผลคือ **ใครก็ตามที่ได้ลิงก์ไป จะเห็นชื่อ-สกุลและยอดเงินของนักเรียนทุกคนในห้อง**
(แก้ไขอะไรไม่ได้ — เขียนได้เฉพาะครูที่ล็อกอิน Google)

ก่อนแจกลิงก์ให้ผู้ปกครอง แนะนำให้
- ใส่เฉพาะข้อมูลที่จำเป็น: **ชื่อ + เลขที่ก็พอ** อย่าใส่เลขบัตรประชาชน เบอร์โทร ที่อยู่
- แจ้งผู้ปกครองว่าลิงก์นี้ไม่ควรส่งต่อออกนอกกลุ่มห้องเรียน
- ถ้าโรงเรียนเคร่งเรื่อง PDPA ให้ใช้ **โหมดเข้มงวด** ด้านล่างแทน

### โหมดเข้มงวด (ให้เฉพาะคนที่ระบุไว้เท่านั้นเข้าดูได้)

ถ้ารับความเสี่ยงข้างบนไม่ได้ ทำ 2 อย่างนี้

1. ปิด provider **Anonymous** ใน Firebase Console → Authentication → Sign-in method
2. เปิด `firestore.rules` ใส่อีเมล Google ของผู้ปกครองในฟังก์ชัน **`isViewer()`**
   (มีตัวอย่างคอมเมนต์ไว้ให้แล้ว)
3. ในไฟล์เดียวกัน เปลี่ยน `allow read: if signedIn();` เป็น `allow read: if isViewer();`
   **ทั้งสองที่** ใต้ `match /savings/{docId}` แล้ว `firebase deploy --only firestore`

ผลคือทุกคนต้องกด "เข้าสู่ระบบด้วย Google" และต้องมีอีเมลอยู่ในรายชื่อ
(แลกกับความยุ่งยากของผู้ปกครองที่ต้องมีบัญชี Google)

> ⚠ **อย่าเอาอีเมลผู้ปกครองไปใส่ใน `isTeacher()`** เพราะฟังก์ชันนั้นคุมสิทธิ์
> **เขียน** ด้วย ผู้ปกครองจะแก้ยอดเงินของนักเรียนได้ทันที

## สิ่งที่ต้องมี

| อย่าง | ใช้ทำอะไร |
|---|---|
| บัญชี Google | สร้างโปรเจกต์ Firebase (ใช้แพ็กเกจฟรี Spark พอ ไม่ต้องผูกบัตร) |
| [Node.js](https://nodejs.org) | สำหรับคำสั่ง `firebase` ตอนติดตั้งและตอน deploy |
| คอมพิวเตอร์ 1 เครื่อง | ใช้ตอนติดตั้งครั้งแรกครั้งเดียว หลังจากนั้นใช้มือถือได้หมด |

ติดตั้ง Firebase CLI (พิมพ์ครั้งเดียวจบ)

```bash
npm install -g firebase-tools
```

# วิธีติดตั้ง (ทำตามทีละขั้น)

## ขั้นที่ 0 · เอาโค้ดจาก GitHub มาไว้ในเครื่อง

เลือกวิธีไหนก็ได้

**วิธี ก — ดาวน์โหลดเป็น zip (ง่ายสุด ไม่ต้องรู้จัก git)**

1. เปิดหน้า repository บน GitHub
2. กดปุ่มเขียว **Code** → **Download ZIP**
3. แตกไฟล์ zip ออกมา จะได้โฟลเดอร์ที่มีไฟล์เหล่านี้

```
index.html              ← ตัวแอปจริง
firebase-config.js      ← ไฟล์เดียวที่ต้องแก้
firestore.rules         ← กฎความปลอดภัย (แก้อีเมลครู)
firestore.indexes.json  ← index ของฐานข้อมูล
firebase.json           ← ตั้งค่า deploy
.firebaserc.example     ← ตัวอย่างไฟล์ระบุโปรเจกต์
```

**วิธี ข — clone ด้วย git** (ถ้าอยากดึงอัปเดตใหม่ ๆ ได้ง่าย)

```bash
git clone https://github.com/kruarifdrm/student-savings-system.git
cd student-savings-system
```

> เปิด Terminal / Command Prompt แล้ว `cd` เข้าไปในโฟลเดอร์นี้ก่อน
> ทุกคำสั่งในคู่มือนี้ต้องรันในโฟลเดอร์นี้

---

## ขั้นที่ 1 · สร้างโปรเจกต์ Firebase

1. เข้า [console.firebase.google.com](https://console.firebase.google.com) → **Add project**
   ตั้งชื่ออะไรก็ได้ เช่น `savings-kruarif` (จะกลายเป็นชื่อลิงก์เว็บด้วย)
   Google Analytics จะเปิดหรือไม่เปิดก็ได้ ไม่ได้ใช้
2. เมนูซ้าย **Build → Firestore Database** → **Create database**
   - location เลือก **`asia-southeast1`** (สิงคโปร์ ใกล้ไทยที่สุด — เลือกแล้วเปลี่ยนไม่ได้)
   - เลือกเริ่มแบบ **production mode** (ปิดทุกอย่างไว้ก่อน เดี๋ยวเราใส่กฎเอง)
3. เมนูซ้าย **Build → Authentication** → **Get started** แล้วเปิดใช้ 2 อย่างในแท็บ **Sign-in method**
   - **Google** — สำหรับครู (กด Enable → เลือกอีเมล support → Save)
   - **Anonymous** — สำหรับผู้ปกครอง *(ถ้าจะใช้โหมดเข้มงวด ข้ามข้อนี้)*
4. กลับหน้าแรกของโปรเจกต์ → กดไอคอน **`</>`** (Web)
   → ตั้งชื่อ app → **Register app** → จะได้ค่าชุด `firebaseConfig` มา **คัดลอกเก็บไว้**

---

## ขั้นที่ 2 · ใส่ค่าลงไฟล์ `firebase-config.js`

เปิดไฟล์ `firebase-config.js` ด้วย Notepad / VS Code แล้วแทนค่าทั้ง 6 บรรทัด
ด้วยค่าที่ได้จากขั้นที่ 1 (แก้ในไฟล์นี้ได้เลย ไม่ต้องก๊อบไปไหน)

```js
window.FIREBASE_CONFIG = {
  apiKey:            "AIza...",
  authDomain:        "savings-kruarif.firebaseapp.com",
  projectId:         "savings-kruarif",
  storageBucket:     "savings-kruarif.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId:             "1:1234567890:web:abcdef"
};
```

> ค่า `apiKey` ของ Firebase **ไม่ใช่รหัสลับ** เปิดเผยได้ตามปกติ
> ตัวที่กันจริงคือ `firestore.rules` ในขั้นถัดไป

---

## ขั้นที่ 3 · ใส่อีเมลเจ้าของระบบใน `firestore.rules`

เปิด `firestore.rules` หาฟังก์ชัน `ownerEmails()` แล้วใส่อีเมล Google ของคุณ

```
function ownerEmails() {
  return [
    'kru.arif@gmail.com'
  ];
}
```

ใส่ที่นี่ **ที่เดียว ครั้งเดียว** — ครูคนอื่นเพิ่มทีหลังได้จากในแอป (ดูขั้นที่ 6)
โดยไม่ต้องแก้ไฟล์นี้และไม่ต้อง deploy ใหม่

> อีเมลนี้เป็น**ทางกลับเข้าระบบเสมอ** ต่อให้เผลอลบครูออกจากรายชื่อในแอปจนหมด
> คุณก็ยังเข้าได้ด้วยอีเมลนี้ จึงไม่ควรลบออกจากไฟล์

---

## ขั้นที่ 4 · เชื่อมโฟลเดอร์นี้กับโปรเจกต์ แล้ว deploy กฎความปลอดภัย

```bash
firebase login          # เปิดเบราว์เซอร์ให้ล็อกอินบัญชี Google ของครู
firebase use --add      # เลือกโปรเจกต์ที่สร้างไว้ แล้วตั้ง alias เป็น default
firebase deploy --only firestore
```

คำสั่งสุดท้ายจะอัปโหลดทั้ง `firestore.rules` และ `firestore.indexes.json`

> **ห้ามข้ามขั้นนี้** ถ้าข้าม แอปจะขึ้น "โหลดข้อมูลไม่สำเร็จ" ตลอด
> เพราะ Firestore แบบ production mode ปิดทุกอย่างไว้ตั้งแต่ต้น

## ขั้นที่ 5 · deploy ขึ้นเว็บ

```bash
firebase deploy --only hosting
```

จะได้ลิงก์แบบ `https://ชื่อโปรเจกต์.web.app` ส่งให้ครูและผู้ปกครองใช้ได้เลย

**ถ้าครูกดเข้าสู่ระบบแล้วขึ้นว่าโดเมนไม่ได้รับอนุญาต** (`auth/unauthorized-domain`)
ให้กดลิงก์ในข้อความ error นั้นได้เลย หรือเข้า Firebase Console →
**Authentication → Settings → Authorized domains** → **Add domain**
แล้วใส่โดเมนของเว็บ เช่น `ชื่อโปรเจกต์.web.app`

> Firebase ใส่โดเมนหลักให้อัตโนมัติ แต่ถ้า deploy ไป hosting site อื่น (multi-site)
> ต้องเพิ่มเอง

### เพิ่มลงหน้าจอโฮมมือถือ

เปิดลิงก์บนมือถือ → เมนูเบราว์เซอร์ → **เพิ่มไปยังหน้าจอโฮม**
จะได้ไอคอนเหมือนแอปจริง เปิดเต็มจอ ไม่มีแถบเบราว์เซอร์

## ขั้นที่ 6 · ใส่รายชื่อนักเรียน (ทำในแอปได้เลย)

เปิดเว็บที่ deploy ไว้ → เลือก **ครู** → **เข้าสู่ระบบด้วย Google** → แท็บ **ตั้งค่า**
แท็บนี้ขึ้นเฉพาะครูที่ล็อกอินแล้วเท่านั้น ผู้ปกครองไม่เห็น

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| **+ เพิ่มนักเรียน** | เพิ่มทีละคน (เลขที่ + ชื่อ) |
| **นำเข้ารายชื่อ** | วางรายชื่อทีละบรรทัด หรือเลือกไฟล์ CSV จาก Excel / Google Sheets |
| **ส่งออก CSV** | ดาวน์โหลดรายชื่อพร้อมยอดคงเหลือ (เปิดใน Excel ภาษาไทยไม่เพี้ยน) |
| **ดาวน์โหลดไฟล์ตัวอย่าง** | ไฟล์ CSV ตัวอย่างไว้กรอกรายชื่อแล้วนำเข้ากลับ |
| **รูป / แก้ไข / ลบ** | ปุ่มท้ายแถวของนักเรียนแต่ละคน |

รูปแบบรายชื่อที่นำเข้าได้

- พิมพ์แค่ชื่อทีละบรรทัด → ระบบไล่เลขที่ให้เอง 1, 2, 3...
- อยากกำหนดเลขที่เอง → `5, สมชาย ใจดี` หรือ `5 สมชาย ใจดี`
- ไฟล์ CSV ที่ส่งออกจากระบบ นำเข้ากลับได้ทันที (คอลัมน์ยอดเงินจะถูกข้าม)
- ชื่อที่มีลูกน้ำต้องอยู่ในเครื่องหมายคำพูด เช่น `2,"สมหญิง, รักเรียน"`
  (Excel ใส่ให้เองเวลา Save as CSV)

**รูปประจำตัว** กด **รูป** ท้ายแถว → เลือกรูปจากเครื่อง ระบบย่อให้อัตโนมัติ
เหลือราว 20 KB ต่อคน ถ้ามีรูปอยู่แล้วจะถามก่อนว่าจะลบรูปเดิมหรือเลือกรูปใหม่

> การนำเข้า**ไม่แตะยอดเงินของคนที่มีอยู่แล้ว**ไม่ว่ากรณีใด ถ้าไม่ติ๊ก
> "เขียนทับชื่อ" เลขที่ที่มีอยู่แล้วจะถูกข้ามไปเฉย ๆ

> **เรื่องลบนักเรียน** ประวัติรายการผูกกับ*เลขที่* ไม่ได้ผูกกับชื่อ
> ลบนักเรียนแล้วรายการเดิมยังอยู่ในระบบ ถ้าเอาเลขที่เดิมไปใช้กับคนใหม่
> คนใหม่จะเห็นประวัติของคนเก่าด้วย — ให้ใช้เลขที่ถัดไปกับคนใหม่แทน

> ถ้ากดปุ่มแล้วขึ้นว่าไม่มีสิทธิ์ = อีเมลที่ล็อกอินไม่อยู่ในรายชื่อครู
> ออกจากระบบแล้วเข้าใหม่ด้วยอีเมลเจ้าของระบบที่ใส่ไว้ในขั้นที่ 3

### เพิ่มครูคนอื่น (ไม่ต้อง deploy ใหม่)

ในแท็บ **ตั้งค่า** เลื่อนลงมาที่ **ครูที่เข้าใช้ระบบได้** → พิมพ์อีเมล Google
ของครูอีกคน → **เพิ่มครู** — มีผลทันที ครูคนนั้นเปิดเว็บแล้วกดเข้าสู่ระบบได้เลย

รายชื่อนี้เก็บอยู่ในฐานข้อมูล (`config/teachers`) และ `firestore.rules` อ่านจากที่นั่น
โดยตรง จึงไม่ต้องแก้ไฟล์หรือ deploy ซ้ำอีก ลบออกก็มีผลทันทีเหมือนกัน

ใครเห็นรายชื่อนี้ได้บ้าง: **เฉพาะครูเท่านั้น** ผู้ปกครองและคนทั่วไปอ่านไม่ได้

## อัปเดตเป็นเวอร์ชันใหม่

แท็บ **ตั้งค่า** ล่างสุดบอกเวอร์ชันที่ใช้อยู่ และมีปุ่ม **ตรวจสอบเวอร์ชันใหม่**
ซึ่งไปเทียบกับ [Releases](../../releases) ของ repo นี้ให้ (ไม่ส่งข้อมูลอะไรออกไป)

เวลามีของใหม่ ให้ทำอย่างใดอย่างหนึ่ง

**วิธี ก — ทับเฉพาะไฟล์แอป (ใครก็ทำได้)**

1. โหลด ZIP ใหม่จาก GitHub (ปุ่มเขียว **Code → Download ZIP**)
2. เอา `index.html` จากอันใหม่ไปทับของเดิม — **ไฟล์อื่นไม่ต้องแตะ**
3. `firebase deploy --only hosting`

`firebase-config.js` และ `firestore.rules` ของคุณอยู่ครบเหมือนเดิม ข้อมูลใน
Firestore ไม่ถูกแตะเลย ถ้า release ไหนบอกว่าแก้ `firestore.rules` ด้วย
ให้เทียบไฟล์แล้วรัน `firebase deploy --only firestore` เพิ่ม

**วิธี ข — ใช้ git (ถ้า clone มาตั้งแต่แรก)**

```bash
git pull
firebase deploy --only hosting
```

`firebase-config.js` อยู่ใน repo ด้วย ถ้า `git pull` แล้วขึ้นว่าชนกับไฟล์นี้
ให้เก็บของตัวเองไว้ด้วยคำสั่ง

```bash
git checkout --ours firebase-config.js
```

แล้ว pull ใหม่ (หรือใช้วิธี ก ซึ่งไม่ต้องยุ่งกับ git เลย)

## การใช้งานประจำวัน

| อยากทำอะไร | ทำยังไง |
|---|---|
| ฝาก/ถอนเงิน | เปิดเว็บ → เลือก **ครู** → เข้าสู่ระบบด้วย Google → แท็บ ฝาก/ถอน → แตะการ์ดนักเรียน → ใส่จำนวนเงิน |
| ให้ผู้ปกครองดู | ส่งลิงก์เดิม ผู้ปกครองเลือก **ผู้ปกครอง** เข้าได้เลย ไม่ต้องล็อกอิน |
| ลบรายการที่ผิด | แท็บ ประวัติ → กดถังขยะท้ายรายการ → ยืนยัน (ยอดจะถูกปรับคืนให้อัตโนมัติ) |
| ปริ้น/ส่งใบสรุป | แท็บ ภาพรวม หรือ ประวัติ → ปุ่มปริ้น → เลือกเดือน/ประเภท |
| เพิ่มนักเรียนกลางเทอม | แท็บ **ตั้งค่า** → *+ เพิ่มนักเรียน* หรือ *นำเข้ารายชื่อ* วางเฉพาะชื่อคนใหม่ |
| ย้ายรายชื่อไปเทอมใหม่ | แท็บ **ตั้งค่า** → *ส่งออก CSV* เก็บไว้ แล้วนำเข้ากลับเมื่อต้องการ |
| เพิ่มครูอีกคน | แท็บ **ตั้งค่า** → *ครูที่เข้าใช้ระบบได้* → พิมพ์อีเมล → *เพิ่มครู* (มีผลทันที ไม่ต้อง deploy) |

## โครงสร้างข้อมูลใน Firestore

```
savings/app                     ← เอกสารตั้งค่า (ยังไม่ได้ใช้เก็บอะไรจำเป็น)
savings/app/students/{เลขที่}    ← { no, name, balance, photo? }
savings/app/transactions/{id}   ← { ts, date, time, studentNo, name, type, amount, balance }
config/teachers                 ← { emails: [...] } รายชื่อครูที่เพิ่มจากในแอป (กฎอ่านจากที่นี่)
```

- `type` เป็น `ฝาก` หรือ `ถอน` เท่านั้น
- `balance` ในรายการ = ยอดคงเหลือ ณ ตอนที่บันทึกรายการนั้น
- แอปดึงประวัติสูงสุด **500 รายการล่าสุด** ต่อการเปิดหนึ่งครั้ง (กันโควตาอ่านบานปลาย)
  ปรับได้ที่ตัวแปร `TX_LIMIT` ใน `index.html`

### สำรองข้อมูล

Firebase Console → Firestore Database → เมนู ⋮ → **Export**
หรือกดปุ่มปริ้น/แชร์เป็นรูปในแอปเก็บไว้เป็นหลักฐานรายเดือนก็ได้

## ความปลอดภัย

ระบบใช้ **Firebase Authentication** คุมสิทธิ์จริงจากฝั่งเซิร์ฟเวอร์ ไม่ใช่แค่ซ่อนปุ่ม
ต่อให้เรียกฟังก์ชันตรงจาก console ของเบราว์เซอร์ Firestore ก็ปฏิเสธการเขียนอยู่ดี

| ใคร | เข้าระบบอย่างไร | ทำอะไรได้ |
|---|---|---|
| ครู | บัญชี Google ที่อยู่ใน `ownerEmails()` (ในไฟล์กฎ) หรือในรายชื่อ `config/teachers` (แก้จากแอป) | อ่านและเขียนทุกอย่าง |
| ผู้ปกครอง / นักเรียน / **ใครก็ตามที่มีลิงก์** | บัญชี anonymous ที่แอปสร้างให้เอง | **อ่านอย่างเดียว** |
| รายชื่ออีเมลครู (`config/teachers`) | — | อ่านได้เฉพาะครู |

ยังควรทำเพิ่ม
- อ่านหัวข้อ [เรื่องความเป็นส่วนตัว](#-อ่านก่อนใช้--เรื่องความเป็นส่วนตัว) ด้านบนให้ครบก่อนแจกลิงก์
- อย่าใส่ข้อมูลส่วนตัวของนักเรียนเกินจำเป็น (ชื่อ + เลขที่ก็พอ)
- จำกัดโดเมนที่ใช้ API key ได้ที่ Google Cloud Console → APIs & Services → Credentials
- ถ้า fork ไปขึ้น GitHub ของตัวเอง **อย่าลืมว่า `firebase-config.js` มีอีเมลครูอยู่**
  ถ้าไม่อยากให้อีเมลเปิดเผย ให้ตั้ง repo เป็น private หรือลบไฟล์นั้นออกจาก git

## แก้ปัญหาที่เจอบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| หน้าจอขึ้น "ยังไม่ได้ตั้งค่า Firebase" | ยังไม่ได้แก้ `firebase-config.js` (ขั้นที่ 2) |
| แก้ `firebase-config.js` แล้วยังขึ้นข้อความเดิม | ไฟล์ยังไม่ได้ขึ้นเว็บ — เปิด `ชื่อเว็บ/firebase-config.js` ดูว่าเห็นค่าที่ใส่ไหม ถ้ายังเป็นค่าเดิมให้ `firebase deploy --only hosting` ซ้ำ แล้วรีเฟรชแรง ๆ (Ctrl+Shift+R) · ถ้าแก้ด้วย Notepad ระวังไฟล์กลายเป็น `firebase-config.js.txt` |
| "โหลดข้อมูลไม่สำเร็จ" | ยังไม่ได้ `firebase deploy --only firestore` (ขั้นที่ 4) |
| `auth/unauthorized-domain` | โดเมนยังไม่อยู่ใน Authorized domains (ขั้นที่ 5) |
| `auth/operation-not-allowed` | ยังไม่ได้เปิด provider Google หรือ Anonymous (ขั้นที่ 1.3) |
| เข้าหน้าครูได้ แต่บันทึกไม่ได้ | ยังไม่ได้ deploy กฎหลังแก้ `ownerEmails()` — รัน `firebase deploy --only firestore` |
| ล็อกอินแล้วขึ้น "อีเมลนี้ไม่มีสิทธิ์ครู" | อีเมลที่กดเลือกไม่อยู่ในรายชื่อ — กดออกจากระบบแล้วเลือกบัญชีใหม่ |
| ประวัติรายคนขึ้นว่าโหลดไม่สำเร็จ | ยังไม่ได้ deploy index — รัน `firebase deploy --only firestore` |

## ค่าใช้จ่าย

ห้องเรียนขนาด 30–40 คน บันทึกวันละไม่กี่สิบรายการ อยู่ในโควตาฟรีของ Firebase
(อ่าน 50,000 / เขียน 20,000 ครั้งต่อวัน) สบาย ๆ ไม่ต้องผูกบัตร

โควตาที่กินมากที่สุดคือการ "อ่าน" ตอนเปิดแท็บประวัติ ระบบจึงจำกัดไว้ที่
500 รายการล่าสุดต่อครั้ง ถ้าห้องใหญ่มากหรือมีผู้ปกครองเปิดดูบ่อย ๆ
ลดค่า `TX_LIMIT` ใน `index.html` ลงได้

การที่กฎอ่านรายชื่อครูจาก `config/teachers` ทำให้ทุกครั้งที่ **ครู** เขียนข้อมูล
มีการอ่านเอกสารเพิ่มอีก 1 ครั้ง (ของผู้ปกครองไม่โดน เพราะกฎไม่ต้องเช็ครายชื่อ)
ระดับห้องเรียนถือว่าไม่มีนัยสำคัญกับโควตาฟรี
