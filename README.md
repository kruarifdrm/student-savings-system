# ระบบออมทรัพย์นักเรียน

เว็บแอปบันทึกเงินออมของนักเรียนในห้อง สำหรับครูประจำชั้น ใช้บนมือถือได้เลย
ไม่ต้องติดตั้งโปรแกรม ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง — เป็นไฟล์ HTML ล้วน
เก็บข้อมูลบน Firebase Firestore (ใช้ฟรีในโควตาปกติของห้องเรียนทั่วไป)

แจกฟรีภายใต้สัญญาอนุญาต MIT เอาไปใช้ แก้ไข หรือแจกต่อได้

---

## ทำอะไรได้บ้าง

- **ฝาก / ถอน** เงินออมรายคน ด้วยแป้นตัวเลขบนมือถือ
- **ภาพรวมทั้งห้อง** ยอดรวม ยอดคงเหลือรายคน แตะดูประวัติรายคนได้
- **ประวัติรายการ** ทั้งห้องหรือรายคน ลบรายการที่บันทึกผิดได้ (ระบบคำนวณยอดใหม่ให้อัตโนมัติ)
- **ปริ้น / แชร์เป็นรูป** ใบสรุปยอดออม ใบประวัติรายการ กรองตามเดือนและประเภทได้
- **โหมดผู้ปกครอง** เข้าดูได้อย่างเดียว ไม่มีปุ่มฝาก-ถอน
- **รูปนักเรียน** ใส่รูปประจำตัวได้ (ไม่ใส่ก็ใช้เลขที่แทน)

---

## สิ่งที่ต้องมี

- บัญชี Google (สำหรับสร้างโปรเจกต์ Firebase — ใช้แพ็กเกจฟรี Spark ได้)
- ถ้าจะ deploy ขึ้นเว็บ: ติดตั้ง [Node.js](https://nodejs.org) และ Firebase CLI
  ```bash
  npm install -g firebase-tools
  ```

---

## วิธีติดตั้ง

### 1 · สร้างโปรเจกต์ Firebase

1. เข้า [console.firebase.google.com](https://console.firebase.google.com) → **Add project** ตั้งชื่ออะไรก็ได้
2. เมนู **Build → Firestore Database** → **Create database** → เลือก location `asia-southeast1` → เริ่มแบบ **production mode**
3. หน้าแรกของโปรเจกต์ → กดไอคอน **`</>`** (Web) เพื่อสร้าง Web app → ตั้งชื่อ → **Register app**
4. จะได้ชุดค่า `firebaseConfig` มา — คัดลอกเก็บไว้

### 2 · ใส่ค่าลงในโค้ด

เปิดไฟล์ `firebase-config.js` แล้วแทนค่าทั้ง 6 บรรทัดด้วยค่าจากขั้นตอนที่แล้ว

```js
window.FIREBASE_CONFIG = {
  apiKey:            "AIza...",
  authDomain:        "myschool.firebaseapp.com",
  projectId:         "myschool",
  storageBucket:     "myschool.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId:             "1:1234567890:web:abcdef"
};

window.DEFAULT_TEACHER_PW = "123456";   // รหัสครูเริ่มต้น เปลี่ยนก่อนใช้จริง
```

### 3 · deploy กฎความปลอดภัย

```bash
firebase login
firebase use --add
firebase deploy --only firestore:rules
```

> ถ้าข้ามขั้นตอนนี้ แอปจะขึ้น "โหลดข้อมูลไม่สำเร็จ" เพราะ Firestore
> แบบ production mode ปิดทุกอย่างไว้ตั้งแต่ต้น

### 4 · ใส่รายชื่อนักเรียน

เปิด `setup.html` (เปิดจากเครื่องตรง ๆ ก็ได้) แล้ว

1. วางรายชื่อนักเรียนทีละบรรทัด → **บันทึกรายชื่อ**
2. ตั้ง **รหัสผ่านครู** ที่จะใช้เข้าระบบจริง

### 5 · deploy ขึ้นเว็บ

```bash
firebase deploy --only hosting
```

จะได้ลิงก์แบบ `https://ชื่อโปรเจกต์.web.app` ส่งให้ครูและผู้ปกครองใช้ได้เลย

> ใช้งานเสร็จแล้วแนะนำให้ลบ `setup.html` ออกจากโฟลเดอร์ที่ deploy
> แล้ว deploy ซ้ำอีกครั้ง เก็บไฟล์ไว้ในเครื่องพอ

## โครงสร้างข้อมูลใน Firestore

```
savings/app                     ← teacherPwHash (SHA-256 ของรหัสครู)
savings/app/students/{เลขที่}    ← { no, name, balance, photo? }
savings/app/transactions/{id}   ← { ts, date, time, studentNo, name, type, amount, balance }
```

`type` เป็น `ฝาก` หรือ `ถอน` — ยอด `balance` ในรายการคือยอดคงเหลือ ณ ตอนนั้น

---

## ⚠ ข้อจำกัดด้านความปลอดภัย (อ่านก่อนใช้จริง)

ระบบนี้ **ไม่ได้ใช้ Firebase Authentication** รหัสผ่านครูถูกตรวจที่ฝั่งหน้าจอ
กฎ Firestore จึงต้องเปิดให้อ่าน-เขียนได้โดยไม่ต้องล็อกอิน แปลว่า

- ใครที่เปิดดูซอร์สของหน้าเว็บ จะเห็นค่า config และเข้าถึงข้อมูลใน `savings/` ได้โดยตรง
- รหัสผ่านครูกันได้แค่คนที่ใช้งานผ่านหน้าจอเท่านั้น

เหมาะกับข้อมูลระดับ **ยอดออมของนักเรียนในห้อง** ที่ไม่ใช่ความลับ
ถ้าจะเก็บข้อมูลที่อ่อนไหวกว่านี้ หรือใช้ทั้งโรงเรียน ควรเพิ่ม Firebase Auth
(ล็อกอินด้วยบัญชี Google ของครู) แล้วแก้ `firestore.rules` ให้เขียนได้เฉพาะครูก่อน

ข้อแนะนำเบื้องต้น
- อย่าใส่ข้อมูลส่วนตัวของนักเรียนเกินจำเป็น (ชื่อ + เลขที่ก็พอ)
- ตั้งรหัสครูใหม่เสมอ อย่าใช้ค่าเริ่มต้น
- จำกัดโดเมนที่ใช้ API key ได้ที่ Google Cloud Console → APIs & Services → Credentials

## ค่าใช้จ่าย

ห้องเรียนขนาด 30–40 คน บันทึกวันละไม่กี่สิบรายการ อยู่ในโควตาฟรีของ Firebase
(อ่าน 50,000 / เขียน 20,000 ครั้งต่อวัน) สบาย ๆ ไม่ต้องผูกบัตร

## ที่มา

พัฒนาขึ้นใช้เองในห้องเรียน แล้วแบ่งปันให้ครูท่านอื่นนำไปใช้ต่อ
ถ้านำไปใช้แล้วติดปัญหาหรืออยากให้เพิ่มอะไร เปิด Issue ไว้ได้
